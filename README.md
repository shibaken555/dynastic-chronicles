# dynastic-chronicles

## コンセプト
EU4のプレイ記録を残すアプリ。
「プレイセッション」を軸に、君主別の日誌・マップ・数値グラフがつながることを目指す。

## 主要機能

### 1. ログ型プレイ日誌（君主制時代区分）
- プレイは君主ごとの「治世」で時代区分される
- 各君主に以下を紐づけ
  - 名前・在位期間（開始年月日・終了年月日）
  - 治世の総評（在位終了時の振り返りメモ）
  - 経済力・軍事力・領土の推移
- 各治世の中で、年代＋カテゴリ（戦争/外交/内政/イベント）＋メモのログを記録

### 2. マップスナップショット
- 年代を指定して版図のスクリーンショットを手動アップロード
- ログのタイムラインと連動して該当年の画像を表示
- 複数プレイ間で同年代の版図を並べて比較可能

### 3. 数値グラフ比較
- 収入・軍事力・開発値などを年ごとに記録
- 同一プレイ内の推移グラフ表示
- 複数プレイを重ねて比較（例: 同じ国での1周目 vs 2周目）
- 数値の記録タイミング
  - 君主の即位・退位時：必須入力
  - 治世期間中：任意タイミングで記録可能

### 4. 認証・認可
- 個人利用アプリだが、学習目的で認証・認可機構を実装する
- 実装方式は今後の技術選定で決定

## 技術スタック

| 領域           | 技術               |
| -------------- | ------------------ |
| フロントエンド | TypeScript + React |
| バックエンド   | Hono               |
| DB             | PostgreSQL         |
| ORM            | Prisma             |
| グラフ         | Recharts           |

### UIコンポーネントの方針
- デザイン・UIコンポーネントはshadcn/uiに統一する。他のUIライブラリは併用しない

## インフラ構成
- ローカル: Docker Compose（Hono + Postgres、volumeでデータ永続化）
- 本番: AWS（詳細は未定）
- 画像ストレージ
  - ローカル環境：Dockerボリュームマウント
  - 本番環境：AWS S3
  - アプリケーション側はストレージ操作を抽象化し、環境変数でローカル/S3を切り替え可能にする
